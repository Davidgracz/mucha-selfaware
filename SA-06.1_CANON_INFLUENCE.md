## 2. Build the weighted local corpus

```powershell
cd F:\mucha-selfaware
python tools\build_selfaware_canon_corpus.py
```

The script preserves existing `data/local_rampancy_corpus.txt` content and only owns:

```text
# BEGIN MUCHA-SELFAWARE SA-06.1 CANON
...
# END MUCHA-SELFAWARE SA-06.1 CANON
```

The current `OnlineLanguage` already bootstraps `data/local_rampancy_corpus.txt`,
so this gives the existing SA-02.6 language model the translated AM/Durandal material.

## 3. Wire the library into SA-06 introspection

Edit `mucha/introspection.py`.

At the imports add:

```python
from pathlib import Path
from .canon_influence import CanonInfluenceLibrary
```

In `IntrospectionEngine.__init__`, directly after:

```python
self.rampancy = rampancy
```

add:

```python
project_root = Path(__file__).resolve().parents[1]
self.canon = CanonInfluenceLibrary(
    project_root / "data" / "rampancy_canon_quotes.jsonl"
)
```

In `answer()`, after the `if/elif` block has produced `answer`
and immediately BEFORE:

```python
self._last_answer = {
```

add:

```python
answer = self.canon.decorate(
    answer,
    kind=kind,
    snapshot=self.rampancy.snapshot(),
)
```

This is intentionally inside IntrospectionEngine. `discord_bot.py` already only
passes `introspection_response` to `_send_learned(...)` when One Brain's
normal arbitration has selected SPEAK, so the canon library does not create
a new action path and does not bypass the connectome.
